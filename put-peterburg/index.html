О базе маршрутов

© OpenStreetMap contributors · ODbL. Справочник включает адреса и названия объектов по Петербургу и Ленобласти из доступного снимка OSM. Это не полный государственный адресный реестр. Номера домов и координаты не выдумываются.

Наземный транспорт: выгрузка «Организатора перевозок» от 19.10.2026 через публичное зеркало ru-gtfs. Расписание и временные объезды не учитываются.

Пригородные маршруты Мурино и порядок станций: © участники OpenStreetMap, ODbL, срез 24.07.2026. Координаты метро: справочник HH. Закрытия станций проверены по сайту метрополитена.

Станции и остановки доступны без интернета. Дома из встроенного справочника доступны без интернета. Для остальных адресов и мест есть интернет-поиск Photon; запрос отправляется только по нажатию поиска. Ответы сохраняются на устройстве на сутки. Пример координат: 59.93, 30.43. Для открытия внешней карты нужен интернет. Встроенная карта улиц: © 2ГИС. Изображения карты загружаются через сервер приложения из 2ГИС. Для отображения участка передаётся область карты; позиция используется только с вашего разрешения. Красная стрелка показывает направление к следующей остановке из базы рейса, а не траекторию движения по дороге. Пешие указания рассчитываются через пешеходный сервис FOSSGIS / OpenStreetMap при открытии соответствующего шага. Для расчёта координаты начала и конца участка передаются сервису. Успешный расчёт сохраняется на сутки. Без интернета ранее рассчитанный участок доступен из кэша; для нового участка можно открыть 2ГИС. Общая оценка поездки использует расстояния по прямой.

Электрички: добавлен участок Девяткино — Лаврики — Капитолово — Кузьмолово. Остальные направления пока не включены. Схема без расписания; остановки конкретного поезда проверяйте перед поездкой.
