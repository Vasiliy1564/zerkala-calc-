О базе маршрутов

© OpenStreetMap contributors · ODbL. Справочник включает адреса и названия объектов по Петербургу и Ленобласти из доступного снимка OSM. Это не полный государственный адресный реестр. Номера домов и координаты не выдумываются.

Наземный транспорт: выгрузка «Организатора перевозок» от 19.10.2026 через публичное зеркало ru-gtfs. Расписание и временные объезды не учитываются.

Пригородные маршруты Мурино и порядок станций: © участники OpenStreetMap, ODbL, срез 24.07.2026. Координаты метро: справочник HH. Сведения о закрытиях взяты из базы приложения; оперативного обновления нет.

База станций, остановок и домов загружается вместе с сайтом. Для остальных адресов и мест используется интернет-поиск Photon; запрос отправляется только по нажатию поиска. Успешные ответы сохраняются в браузере на сутки. Геолокация работает с вашего разрешения. Для поиска адресов текст запроса передаётся Photon, для пешего расчёта координаты передаются FOSSGIS / OpenStreetMap. Пример координат: 59.93, 30.33. Для открытия внешней карты нужен интернет. Пешие указания рассчитываются через пешеходный сервис FOSSGIS / OpenStreetMap при открытии соответствующего шага. Для расчёта координаты начала и конца участка передаются сервису. Успешный расчёт сохраняется на сутки. Ранее рассчитанный участок может быть доступен из кэша браузера; для нового участка нужен интернет. Общая оценка поездки использует расстояния по прямой.

Электрички: добавлен участок Девяткино — Лаврики — Капитолово — Кузьмолово. Остальные направления пока не включены. Схема без расписания; остановки конкретного поезда проверяйте перед поездкой.
